WhatsApp Intake · Simulator
VPS Lakeshore · Kochi

Report it like you’d text a friend.

Staff message the hospital’s WhatsApp number in plain language — English, Malayalam or Manglish, photo optional. AI triage reads the message and files a properly classified ticket into the same Lakeshore One queues agents already work: right desk, right category, right priority, right zone. Updates come back on WhatsApp.
1
Message received Meta WhatsApp Cloud API webhook delivers it to the Lakeshore One server. First message links the number to an employee ID.
2
AI triage Claude classifies desk, category, priority (ITIL P1–P4), campus zone and patient-care impact — with a keyword fallback if the AI is unreachable.
3
Ticket in the queue Created through the same role-checked pipeline as the app — SLA clock starts, agents see it instantly, audit trail records it.
4
Updates flow back Taken up, resolved, comments — the reporter is notified on WhatsApp and can reply STATUS, CLOSE or CANCEL any time.
